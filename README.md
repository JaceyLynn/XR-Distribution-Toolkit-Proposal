# XR Distribution Toolkit: initial proposal

Presentation page for the XR Distribution Toolkit proposal (MIT Open Documentary Lab × IDFA DocLab).

The whole page, including the interactive sketches and venue data, is a single self-contained file: `index.html`. Open it in a browser, or serve it with GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).

Venue names in the sketches come from an Airtable export of the research team's venue list.
