# XR Distribution Toolkit

Presentation pages for the XR Distribution Toolkit (MIT Open Documentary Lab × IDFA DocLab).

- `index.html`: stakeholder page. The problem, the Guided journey and the Pathway (both clickable), and how the two can work together.
- `initial_1019.html`: the initial proposal page from 19 October 2026, with all three proposals (Guided journey, Pathway, Atlas), filters and the build plan.

Each page is a single self-contained file, including the interactive sketches and venue data. Open it in a browser, or serve the repository with GitHub Pages (Settings → Pages → Deploy from a branch → `main`, `/ (root)`).

Venue names in the sketches come from an Airtable export of the research team's venue list.
